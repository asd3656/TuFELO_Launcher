# TuFlauncher

TuF 클랜 ELO 시스템 연동 런처입니다.  
스타크래프트 리마스터 리플레이를 자동 감지해 전적을 Google Sheets에 기록합니다.

---

## 설치 방법

### 1. 다운로드

최신 릴리즈 페이지에서 다음 두 파일을 같은 폴더에 받습니다.

| 파일 | 설명 |
|------|------|
| `TuFlauncher.exe` | 런처 실행 파일 |
| `screp.exe` | 리플레이 파서 (필수 동봉) |

> `screp.exe`를 별도로 받아야 하는 경우:  
> [https://github.com/icza/screp/releases](https://github.com/icza/screp/releases) 에서 Windows 빌드를 받아 같은 폴더에 놓으세요.

### 2. 폴더 구조 확인

```
TuFlauncher\
├── TuFlauncher.exe
└── screp.exe
```

`config.json`은 첫 실행 시 자동으로 생성됩니다.

---

## 사용 방법

1. **`TuFlauncher.exe`** 를 실행합니다.
2. **활동명** 드롭다운에서 본인 닉네임을 선택합니다.
3. **리플레이 폴더** 경로를 확인합니다.  
   기본값: `내 문서\StarCraft\Maps\Replays`
4. **설정 저장** 버튼을 눌러 저장합니다.
5. **런처 시작** 버튼을 누릅니다.
6. 스타크래프트에서 게임을 마치면 자동으로 전적이 기록됩니다.

---

## 전적 기록 조건

다음 조건이 모두 충족되어야 자동으로 기록됩니다.

- 방 제목에 `$친선` 또는 `$내전` 등 `$` 태그가 포함되어 있어야 합니다.
- 1v1 게임이어야 합니다.
- 두 플레이어 모두 클랜원 목록에 있어야 합니다.
- 런처를 실행한 본인이 해당 게임의 참여자여야 합니다.
